# SimLab - Ambientes Inteligentes de Simulação de Redes

## Visão Geral

O **SimLab** é um sistema feito para facilitar as aulas práticas de redes de computadores no IFTO Campus Palmas.

Em vez de o professor ter que configurar cada computador do laboratório manualmente antes da aula, o SimLab permite escolher o ambiente de prática (usando simuladores como EVE-NG e eNSP) direto por uma **interface simples**. O sistema cuida de carregar tudo automaticamente para as máquinas dos alunos através da rede.
